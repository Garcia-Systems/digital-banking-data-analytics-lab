# Part II investigation worksheet

**Question:** Harbor's account-opening completion rate appears to have declined. What can we responsibly say from the available synthetic data?

1. Rebuild SQLite and establish the SQL numerator, denominator, and session grain.
2. Define explicit UTC baseline and comparison windows; report point and relative changes.
3. Segment by channel, then device; always retain session counts.
4. Run the defined quality checks on the data used (do not silently clean).
5. Write an evidence-bounded conclusion: distinguish observations and associations from causes, list limitations, and name the next evidence to inspect.

This is investigation, not an experiment or prediction. Part III will add journey and funnel tools.
