# Full-Book Learning Map

The six Parts form one investigation path rather than six independent curricula.

```text
BUSINESS / PRODUCT QUESTION (Chapters 0, 3)
            ↓
QUESTION FRAMING + ANALYTICAL UNIT (2–3)
            ↓
DATA INSTRUMENTATION + PROVENANCE (1–2)
            ↓
DATA QUALITY (7)
            ↓
SQL / ANALYSIS (4)
            ↓
TIME + SEGMENTATION (5–6)
            ↓
MEMBER JOURNEY (8)
            ↓
FUNNEL + ABANDONMENT (9–10)
            ↓
DIGITAL EXPERIENCE SIGNALS (11–13)
            ↓
API / INTEGRATION (14–15)
            ↓
DATABASE + ERROR / INCIDENT (16–17)
            ↓
CROSS-LAYER VIEW + HYPOTHESIS (17, 22–23)
            ↓
BASELINE / COHORT / EXPERIMENT (18–20)
            ↓
DECISION + COMMUNICATION (21–22)
            ↓
INTEGRATED INVESTIGATION (23)
```

| Part | Skill progression | Executable outcome |
| --- | --- | --- |
| I — Analytics thinking | Define events, dimensions, metrics, KPIs, provenance, units, and answerable questions. | Inspect the core fixture and assess question readiness. |
| II — SQL, time, segmentation, quality | Query explicit grains; compare declared windows; locate segment differences; validate evidence. | Reconcile Python and SQL and detect dirty data. |
| III — Journeys and digital experience | Reconstruct applications; build funnels; locate abandonment; inspect device, navigation, and campaign context. | Produce an evidence-bounded experience investigation. |
| IV — Full-stack telemetry | Preserve request, operation, provider-call, query, and error grains while correlating layers. | Trace an application and evaluate competing engineering explanations. |
| V — Decisions and communication | Declare baselines, check cohort maturity, interpret assigned experiments and guardrails, tailor a dashboard/report. | Generate decision evidence without turning it into an automatic verdict. |
| VI — Capstone | Apply the full progression to an initially ambiguous decline. | Discover when, where, and across which layers the pattern appears; state a leading hypothesis and limitations. |
