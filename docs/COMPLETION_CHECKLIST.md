# Completion Checklist

- [ ] Chapter 0 — I can convert a vague concern into defined observations and hypotheses.
- [ ] Chapter 1 — I can identify each evidence source and preserve its provenance.
- [ ] Chapter 2 — I can distinguish events, dimensions, metrics, and KPIs and label denominators.
- [ ] Chapter 3 — I can assess whether available fields can answer a question.
- [ ] Chapter 4 — I can use readable SQL without multiplying rows or confusing grains.
- [ ] Chapter 5 — I can compare declared time windows and distinguish percentage points from relative change.
- [ ] Chapter 6 — I can segment a metric while retaining counts and checking composition.
- [ ] Chapter 7 — I can detect quality defects before trusting a result.
- [ ] Chapter 8 — I can reconstruct an application journey without inventing missing stages.
- [ ] Chapter 9 — I can construct and interpret a multi-stage funnel without confusing event counts with application counts.
- [ ] Chapter 10 — I can locate observed abandonment and separate it from intent or cause.
- [ ] Chapter 11 — I can compare mobile and desktop with equivalent populations and windows.
- [ ] Chapter 12 — I can analyze navigation and normalized search signals without retaining raw search text.
- [ ] Chapter 13 — I can analyze tagged campaign arrivals without claiming causal attribution.
- [ ] Chapter 14 — I can calculate request error rates and nearest-rank p95 latency.
- [ ] Chapter 15 — I can distinguish provider-call failures, logical operations, retries, and recovery.
- [ ] Chapter 16 — I can investigate query latency, scan size, and repeated-query patterns.
- [ ] Chapter 17 — I can build a cross-layer incident timeline without treating sequence as cause.
- [ ] Chapter 18 — I can predeclare and interpret a baseline, target, and comparison period.
- [ ] Chapter 19 — I can compare cohorts only after checking observation maturity.
- [ ] Chapter 20 — I can evaluate assigned variants, uncertainty, and guardrail metrics.
- [ ] Chapter 21 — I can build audience-specific dashboards with visible context and denominators.
- [ ] Chapter 22 — I can communicate observations, associations, hypotheses, and experimental evidence precisely.
- [ ] Chapter 23 — I can conduct the integrated investigation and defend a bounded leading hypothesis.
