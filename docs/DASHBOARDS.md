# Offline Harbor dashboard

Run `python3 scripts/build_dashboard.py` to write `dist/dashboard.html`. It uses semantic HTML and embedded CSS only: no CDN, remote font, JavaScript, tracking, or network request. Engineering, Digital Product, and Operations sections answer different questions from one consistent synthetic metric object. Every displayed rate is paired with an observation period or denominator/context. Use signals to drill into segments, journeys, API/vendor/database telemetry, and then investigate; never present association as explanation.
