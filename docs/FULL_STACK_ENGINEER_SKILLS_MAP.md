# Full-Stack Engineer Skills Map

This map links broadly useful engineering capabilities to practice in the textbook. It does not reproduce an employer's requirements and does not guarantee job readiness.

| Capability | Chapters | Executable practice |
| --- | --- | --- |
| SQL and relational-data reasoning | 4, 7, 9, 12–13, 16, 23 | Build SQLite; run `chapter_04_sql.py`; inspect `sql/01`–`07`; verify distinct application denominators and safe joins. |
| API behavior | 14, 17, 23 | Run `chapter_14_api_analytics.py`; compare request errors and p95; trace capstone requests. |
| Third-party integrations | 15, 17, 23 | Run vendor analytics and distinguish provider calls from logical operations and retry recovery. |
| Application troubleshooting | 8–17, 23 | Reconstruct journeys, locate stage changes, then correlate purpose-limited telemetry across layers. |
| Digital-experience analysis | 8–13, 21, 23 | Build application funnels; investigate abandonment, navigation, search, campaign context, and audience dashboards. |
| Mobile-first analysis | 6, 11, 14, 18–20, 23 | Compare mobile/desktop with explicit counts; inspect mobile verification, guardrails, and assigned variants. |
| Testing and validation | 4, 7, 9, 15, 19–20, 23 | Run `pytest`, data regeneration, Python/SQL agreement, quality checks, maturity checks, assignment checks, and cross-layer tests. |
| Database investigation | 4, 16–17, 23 | Build the disposable database; inspect query plans, scan size, repeated queries, latency, and correlated alternatives. |
| Analytics-driven decisions | 3, 18–22 | Predeclare questions/windows/targets; assess cohorts and experiments; inspect guardrails and decision options. |
| Cross-team communication | 1, 21–23 | Generate engineering, product, operations, and executive views while preserving facts and certainty. |

The professional habit tying these together is to move from a precise question to the correct grain, validate evidence, investigate across boundaries, and communicate a bounded conclusion plus a useful next action.
